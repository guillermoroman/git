### Ejercicio 1: GitHub desde IntelliJ

1. Crea un proyecto Java en IntelliJ IDEA. Establece en el diálogo de creación de proyecto que se ha de crear un repositorio Git.
2. Imprime por pantalla desde main un "Hola Mundo" y haz un primer commit.
3. Comparte dicho proyecto en GitHub como un repositorio público.
4. Accede a tu repoitorio desde GitHub y modifica tu programa desde el navegador para incluir una exclamación en esta expresión
5. Actualiza tu versión local del repositorio para que tenga la misma versión que tenemos en GitHub.
